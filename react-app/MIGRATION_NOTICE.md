## 为什么迁移？

- **更好的移动端体验**：Flutter 原生性能，流畅度更高
- **独立维护**：两个仓库互不干扰，便于版本管理
- **专注移动端**：个人开发主要使用场景在移动端

## React 版本状态

- ✅ 功能完整，可正常使用
- 🔒 不再添加新功能
- 🐛 仅修复 critical bugs（如有）
- 📦 代码已存档在 `v1-final` tag

## 如何使用旧版本

```bash
# 克隆 React 版本
git clone https://github.com/cnxin/lifelog.git
cd lifelog

# 查看最终版本
git checkout v1-final

# 安装依赖
npm install

# 运行开发服务器
npm run dev
```
