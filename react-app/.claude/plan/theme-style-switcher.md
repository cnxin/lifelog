# 多风格主题切换方案

**目标**: 保留当前原版视觉，同时新增 3 个小清新风格，并允许用户在设置中自由切换。  
**范围**: 全局设置类型、设置持久化、Settings 页面、App 根容器主题标记、CSS 主题变量。  
**原则**: 不破坏现有数据；默认仍为当前原版；主题切换只影响视觉，不影响业务逻辑。

## 执行清单

- [x] 1. 确认当前设置模型和全局布局挂载点
- [x] 2. 扩展设置类型，新增 `themeStyle` 并设置默认值 `classic`
- [x] 3. 在 App 根容器挂载主题 class / data 属性
- [x] 4. 在 Settings 中新增主题选择区：原版 / 奶油纸感 / 薄荷留白 / 晨雾极简
- [x] 5. 将三个 Demo 方向转为全局主题变量和关键组件覆盖样式
- [x] 6. 保留 Demo 预览，用于对比当前选择
- [x] 7. 运行构建检查
- [x] 8. 汇报预览路径和切换方式

## 主题选项

- `classic`: 原版紫橙渐变
- `cream`: 奶油纸感
- `mint`: 薄荷留白
- `mist`: 晨雾极简

## 验收标准

- 设置页可以切换 4 种风格。
- 切换后全局主要页面、卡片、按钮、控件色彩同步变化。
- 关闭/刷新后主题选择保留。
- 默认主题不改变现有用户视觉。
