# 小清新 UI 改造方向 Demo 方案

**目标**: 在不直接改全局主题的前提下，提供几个更清爽、不花哨的视觉方向 Demo 供选择。  
**范围**: Settings 页面新增展示区 + 局部 CSS 样式。  
**原则**: 不影响现有业务流程；只展示视觉方向，不替换现有全局样式。
