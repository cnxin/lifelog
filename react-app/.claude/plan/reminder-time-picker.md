# 提醒时间选择器边界修复方案

**项目**: LifeLog React App  
**问题**: 原生 `type="time"` 在提醒时间里表现为无边界滚轮/输入体验  
**目标**: 小时只显示 00-23，分钟只显示 00-59，保持移动端精致控件风格

---

## 执行清单

- [x] 1. 新增有限时间选择器组件，提供 24 小时和 60 分钟列表
- [x] 2. 替换提醒设置里的生日/纪念日/定期联系/回忆回顾时间输入
- [x] 3. 替换控件 Demo 里的时间输入
- [x] 4. 补充时间选择器样式和浮层交互
- [x] 5. 运行 TypeScript 检查
- [x] 6. 汇报预览路径和验证结果

## 验收标准

- 小时列表只包含 `00` 到 `23`。
- 分钟列表只包含 `00` 到 `59`。
- 选择小时/分钟不会改变页面布局。
- 只有一个有限浮层，不出现原生无限滚轮。
- 修改提醒时间后仍保存到现有 `ReminderSettings`。
