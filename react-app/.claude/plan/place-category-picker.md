# 地点类型选项化方案

**目标**: 将地点表单里的“类型 / 分类”从自由输入改成选项控件。  
**范围**: EntrySheet 编辑地点、快速新增地点。  
**原则**: 保持 `category` 字段名不变，不影响保存逻辑。

## 执行清单

- [x] 1. 确认当前地点类型字段位置和已有分类值
- [x] 2. 抽取地点类型选项列表
- [x] 3. 替换编辑地点分类输入为 SelectPicker
- [x] 4. 替换快速新增地点类型输入为 SelectPicker
- [x] 5. 运行构建检查
- [x] 6. 汇报预览路径

## 验收标准

- 新增/编辑地点时类型不再是原生输入框。
- 字段仍提交为 `category`。
- 默认值仍为“餐厅”。
