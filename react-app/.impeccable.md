# LifeLog Design Context

## Design Context

### Users
LifeLog 的用户是在手机上记录重要人物、地点和回忆的人。使用场景偏私人和移动端：快速记录一段关系、一次经历、一个地点，并在之后回看人物关系、生日纪念日、照片和回忆线索。当前阶段还包含 Android APK 真机测试场景。

### Brand Personality
柔和、私人、温暖、轻量精致。界面应像一本贴身的生活记录本，不像企业后台，也不应显得冰冷、复杂或工具化。

### Aesthetic Direction
延续现有移动端优先的毛玻璃卡片、紫橙柔和渐变、圆角、轻阴影和紧凑手机框架。控件应有触控友好的尺寸、清晰的状态反馈和精致但克制的细节。避免浏览器默认控件的粗糙感，避免过度装饰、霓虹科技感和笨重卡片嵌套。

### Design Principles
1. 移动端优先：触控目标清晰，控件高度和间距适合单手操作。
2. 温暖克制：用柔和渐变、半透明背景和细腻阴影增强质感，不用强烈视觉噪音。
3. 功能不被装饰淹没：设置、表单和提醒配置应保持一眼可懂。
4. 原生能力优先：能用原生 select/input 保持稳定时，不引入复杂自定义交互。
5. 状态完整：默认、焦点、按下、禁用等状态都应可见且一致。
